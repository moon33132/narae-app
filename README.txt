나래반 학급 관리 웹앱 사용 설명서
=====================================

■ 설치 (처음 한 번만)
-----------------------
1. 명령 프롬프트(cmd)에서 아래 명령 실행:

   pip install flask

2. 이 폴더(narae_app) 전체를 선생님 PC 아무 곳에나 저장


■ 실행 방법
-----------
1. server.py 가 있는 폴더에서:

   python server.py

2. 화면에 표시되는 IP 주소 확인
   예) 선생님/학생 접속: http://192.168.1.5:5000

3. 학생들 크롬북에서 위 주소를 주소창에 입력


■ 접속 방법
-----------
[학생]
- 브라우저에서 http://[선생님IP]:5000 접속
- "학생" 탭에서 자기 번호(1~22) 클릭 → 입장

[선생님]
- 같은 주소 접속
- "선생님" 탭 → 비밀번호: narae1234
- 비밀번호는 server.py 파일 안 TEACHER_PW 에서 변경 가능


■ 주요 기능
-----------
[학생 화면]
  ✋ 출석 체크       - 버튼 한 번으로 출석 기록
  📢 공지사항        - 선생님이 올린 공지 확인
  📥 파일 다운로드   - 선생님이 배포한 학습지/자료 다운로드
  📤 과제 제출       - 파일 업로드로 과제 제출
  📝 퀴즈/설문       - 선생님이 만든 퀴즈 응답

[선생님 화면]
  ✋ 출석 현황       - 번호별 출석/결석 한눈에 확인 + CSV 저장
  📢 공지 등록/삭제  - 학생 화면에 즉시 표시
  📤 파일 배포       - 학생들이 다운로드할 파일 등록
  📥 제출 파일 확인  - 학생들이 올린 파일 다운로드/삭제
  📝 퀴즈 만들기     - 단답형/객관식 퀴즈 생성, 결과 통계 확인


■ 퀴즈 문항 작성법
------------------
  단답형: 질문만 입력
  예) 우리나라 수도는?

  객관식: 질문|선택1,선택2,선택3
  예) 가장 좋아하는 계절은?|봄,여름,가을,겨울


■ 저장 위치
-----------
  학생 제출 파일  → narae_app/uploads/
  배포 파일       → narae_app/shared/
  출석/공지 데이터 → narae_app/data/


■ 주의사항
----------
- 선생님 PC와 학생 크롬북이 같은 와이파이에 연결되어 있어야 해요
- 수업 끝나면 cmd 창을 닫으면 서버가 종료됩니다
- 데이터는 모두 선생님 PC 로컬에 저장됩니다
